# 讲师演示手册

## 课前准备

1. 使用 Node.js 24 LTS，在两个独立目录分别克隆 demo 和 complete；分别执行 `npm ci`、`npm run build`。
2. 启动 complete，关闭浏览器翻译，投影建议 1280×900 或更大；浏览器可缩放到 80–90% 使实验台完整可见。窄屏会自动改为纵向布局。
3. 课堂中切换两个目录/终端，避免在仍运行 Vite 时切分支或修改依赖。若改动 package-lock，重新 `npm ci` 并重启服务。
4. 将 [离线演示录像](media/agent-walkthrough.webm) 下载到讲课电脑。录像无音轨，讲解词见下面路线。还可提前构建后保持 `npm run preview` 运行，网站本身不依赖外部接口或字体 CDN。
5. 本站所有代码修改与命令输出都是教学模拟，不会修改讲师磁盘文件。真实 CLI 演示在独立的学生练习目录进行。

## 开场 3–5 分钟

- **0:00–0:30**：播放开场。“这一句需求，会经过模型、控制层、工具和项目环境，最后得到构建证据。”
- **0:30–1:00**：比较只生成回答与让 Agent 执行。“模型能提出代码，工具使改动真正发生。”
- **1:00–2:00**：进入实验台，点击演示视图。播放到第 6 步。先拒绝，指出文件没有修改；再批准，点下一步观察文件差异和抽签预览。
- **2:00–3:00**：点第 10 步，解释 `theme.css` 不存在。点第 11 步观察修复为 `style.css`；点第 12 步看 `Build passed`。点击抽签按钮体验成果。
- **3:00–4:00**：回退到读取文件，观察文件、上下文、终端一起还原。强调工具结果如何成为下一轮的输入。
- **4:00–5:00**：退出演示视图，展示上下文摘要与一个扩展能力，点击“开始创建我的网站”衔接 demo。

## 操作说明与恢复

- 实验台：空格播放/暂停、左右键单步。焦点停在按钮、链接、输入框、summary 上时，按键遵循浏览器默认行为；可点击实验台空白位置后继续快捷键。
- 步骤 6 在手动模式等待。批准后停在步骤 7，按下一步或播放继续；拒绝后保持未执行状态。
- 时间线任意跳转属于历史回放。跳过审批节点将还原已批准路径，不能用它说明真实权限被绕过。
- “重播”回到第一步并暂停，清除后续差异、构建结果与审批决定；速度和批准模式保持当前设置。
- 工具章节是独立沙盘，不会影响主实验台；上下文读取按钮也只增加教学展示来源。
- 减少动态效果模式保留手动开场播放与全部控制，默认不开自动播放。
- 网络波动：播放本地 WebM；开发服务出错：Ctrl+C，`npm ci` 后重新 `npm run dev`。

## 内容核对

模型提出请求；Agent 控制层管理上下文、权限和调度；工具读取/编辑环境并返回可观察结果。模式、规则与工具类型共同影响是否确认，不应将沙盘审批描述为所有操作的固定弹窗。

项目规则是持久文件，当前会话有对话与工具结果，摘要可能丢失细节。网页容量条不是 token 测量。四类扩展增强循环，不取代验证。

官方资料链接在网站末尾与 README 中维护。若 Claude Code 的命名或行为更新，应同时更新文案和演示脚本。
